Dialogue Deep Representation Disentanglement for Conversational Speech Synthesis

Abstract

Conversational Speech Synthesis aims to generate natural and expressive speech by leveraging dialogue history. We propose Dialogue Deep Representation Disentanglement (DDRD), which explicitly separates dialogue history into modality-specific linguistic and acoustic representations and a shared modality-invariant semantic representation. LLM-guided contrastive learning further organizes the shared representation using dialogue-level semantic supervision, while Dialogue Deep Representation Fusion integrates the disentangled context for expressive speech generation.

Experiments

Comparative experiment. We compare DDRD with representative conversational speech synthesis systems spanning multimodal context encoding, fine-grained context modeling, contrastive learning, emotional context modeling, and context interaction modeling.
